# TICKET-00: App Shell and Design System

## Goal
Establish a global design system and build the main application shell with navigation.

## Tasks
1. Set up global CSS styling variables (color palette, typography, glassmorphism shadows, light/dark themes).
2. Build the main layout (App Shell) containing a navigation sidebar (tabs for Dashboard, Certificate Generator, Classes, Settings).
3. Ensure the app window layouts are fully responsive and adapt to window resizing.
