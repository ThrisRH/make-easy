# TICKET-03: Circular Crop and Alignment for Student Images

## Goal
Allow users to click on a student image to adjust its centering/cropping to fit a circular frame.

## Tasks
1. Handle click events on the student image inside the preview.
2. Open a modal or overlay showing the image cropping interface.
3. Allow adjusting the crop area or shifting/scaling the image to center it in a circle.
4. Update the cropped image output in the certificate state.
